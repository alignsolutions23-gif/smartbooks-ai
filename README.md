# SmartBooks AI — Mobile First

This version is redesigned for Android/mobile screens first.

## Run on a computer
1. Install Node.js LTS.
2. Extract the ZIP.
3. Open the folder in VS Code.
4. Run `npm install`
5. Run `npm run dev`
6. Open `http://localhost:3000`

## Test on your Android phone on the same Wi‑Fi
1. On the computer run `npm run dev -- --hostname 0.0.0.0`
2. Find your computer's local IP, for example `192.168.1.10`
3. On the phone, open `http://192.168.1.10:3000`

This is a UI prototype. The next production stage is Supabase authentication/database, real double-entry accounting, GST calculations, PDF invoices and cloud backup.
